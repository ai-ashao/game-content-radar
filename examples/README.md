# 参考研究包：有真实出处，不是已完成文章

三份JSON分别对应买得明白、经典再发现、作品背后。网页“题材与资料 → 导入研究包”中，粘贴一份JSON即可。

这些不是当天热点或已审核文章：没有实时价格、虚构评分/玩家数，没有本人实机体验。每一项导入后主张都重置为待核验；补齐缺口、亲自打开出处再核验。

| 文件 | 资料来源 | 明确缺口 |
|---|---|---|
| 01-buy-smart-review-scope.json | Steam官方评论API文档 | 没有当前具体游戏的分子分母，需本机补充 |
| 02-classic-portal2-coop.json | Portal2官方商店介绍 | 没有实机对照画面，待研究一个具体场景 |
| 03-creator-miyazaki-bloodborne.json | PlayStation Blog 2015年访谈 | 旧采访核对、作品画面、若使用正式总监职务需补credits |

本包只提供必要摘要，不复制整篇文章，也不认为一个URL就等于完整研究。这些材料不代表M5实际发帖测试已经通过。

## 网页AI返回格式

先从编辑台复制已经形成的资料包。让网页AI只使用已核验材料，然后返回：

```json
{
  "title": "与材料一致的标题",
  "title_candidates": ["标题一", "标题二", "标题三"],
  "body_markdown": "正文核心段落用 [C:真实主张ID] 定位到你的材料。",
  "comment_hook": "有自然问题才写，没有可为空",
  "used_claim_ids": ["替换成研究包中真实的主张ID"]
}
```

以上只是字段结构，不能直接导入为真实内容。标题应位于候选中，核心数字和引语应来自核验事实。模型输出之后仍需人审核。
